# Размер AI-чек-листа: из идеи — 8–12 пунктов, из источника — все пункты

**Суть:** правило размера живёт в серверном промпте `generate_checklist` (gitignored `firebase-functions/prompts_private.py`), не в клиенте. Только идея, без своих пунктов → сфокусированный плоский список из 8–12 самых полезных пунктов; больше — лишь по явной просьбе о подробном или полном списке. В источнике уже есть пункты (фото, PDF, вставленный текст, ссылка, запись) → сохраняется каждый, без лимита. Проверка — живой тест `firebase-functions/tests/test_generate_checklist_size.py` против задеплоенной функции.

## Проблема / Контекст

Пример «собраться на море» в онбординге дал чек-лист из 43 пунктов. Онбординг и создание из текста зовут один `generate_checklist`, а промпт просил «comprehensive checklist» без цели по размеру. До фикса: 33 пункта на «Pack for a beach trip», 38 на «Собраться на море» (источник: `test_generate_checklist_size.py` против ревизии `generate-checklist-00042-civ`).

## Решение

- Из промпта убрано «comprehensive». Добавлен блок про размер: источник с пунктами — сохранить все; только идея — 8–12 пунктов, плоским списком, без мелких и почти повторяющихся пунктов; больше 12 — только по явной просьбе.
- Правило про папки больше не говорит о количестве: папки не меняют размер списка.
- Задеплоена только `generate_checklist`, ревизия `generate-checklist-00043-ruk`. После фикса: 10 пунктов (EN) и 11 (RU), без папок; вставленный список из 20 пунктов вернулся целиком — 20 (источник: тот же тест против `00043-ruk`).
- Канонический `firebase-functions/prompts_private.py` (gitignored) лежит в основном checkout; копию, с которой шёл деплой, вернули туда — хеши совпадают.

## Почему именно так

- **Сервер, а не клиент.** Обрезка на клиенте теряет содержание: важное не обязательно в начале. Подсказка только из онбординга оставила бы большим обычное создание. Владелец: чинить везде.
- **Два режима, а не потолок.** Та же функция извлекает пункты из фото и текста; голое «не больше 12» срезало бы реальный список — отсюда защитный кейс на 20 пунктов.
- **Норма 8–12** — выбор владельца: список читается с одного-двух экранов.

## Связанные файлы

- `firebase-functions/prompts_private.py` — gitignored, текст промпта в git не попадает
- `firebase-functions/main.py` — `generate_checklist`
- `firebase-functions/tests/test_generate_checklist_size.py`
- `feature/analyze/src/commonMain/kotlin/com/antonchuraev/homesearchchecklist/feature/analyze/data/repository/AnalyzeRepositoryImpl.kt`
- Задача: `docs/archive/onboarding-refresh-2026-11-04.md`
