## Цель (продуктовая)

При английском UI таб Inbox показывал заголовок «Входящие». Имя системного Inbox должно
быть на текущем языке UI на всех экранах, где оно видно.

## Технический план

Определять имя Inbox при показе из ресурсов по `isInbox`; БД и синк не трогать; red-репро
тест на чистое правило.

## Лог итераций

### Итерация 1 — 2026-10-26 — feature-expert: хелпер `checklistDisplayName` + 9 поверхностей + `TodayReminderInfo.isInbox` → тесты red (3 падения) → green

## Выводы

Корень — имя Inbox пишется в БД один раз через `getString` на языке момента создания, экраны
печатали его как есть. Исправлено на уровне показа. Решение и вынесенные из скоупа места —
[solution](../solutions/system-row-name-localized-at-display-2026-10-26.md).

## Предложения по улучшению агентов

- feature-expert сам нашёл, что `getString` в VM не переживает смену языка внутри приложения, и
  выбрал `stringResource` — паттерн записан в его память; в агенте его нет.
